# dotnet-fhirconnect

A C# / .NET implementation of the
[FHIRconnect](https://sevkohler.github.io/FHIRconnect-spec/) mapping
specification — bidirectional transformation between openEHR
Compositions and HL7 FHIR Resources, packaged as a NuGet library and a
`dotnet tool` CLI.

**Status:** pre-alpha. Walking-skeleton scope only; do not use in
production. See [`scratch/0527-01/plan.md`](scratch/0527-01/plan.md)
for the current roadmap.
